# مغامرات فريدة — مشروع لعبة Android

لعبة مغامرات وتعليم عربية للأطفال بطلتها فريدة. المستودع هو مصدر التطوير والبناء.

## متطلبات الإصدار النهائي
- المستخدم طلب APK أكبر من 100 ميجابايت، على أن يكون الحجم ناتجاً عن محتوى حقيقي مستخدم داخل اللعبة، وليس ملفات حشو.
- واجهة عربية، تحكم لمس ثابت، عوالم ومراحل مفتوحة، وأنشطة للحيوانات والأشكال والألوان والحروف.
- موسيقى ومؤثرات متنوعة بجودة مناسبة، وتشغيل دون اتصال.

## الحالة الفعلية
المشروع ما زال نموذجاً أولياً، وليس منتجاً تجارياً مكتملاً. أُضيف مولّد لثلاث مقطوعات موسيقية أصلية متعددة الطبقات، وتُنشأ ملفات WAV وقت البناء وتُستخدم داخل العوالم. يتحقق مسار البناء من وجود المقاطع الثلاثة داخل APK ومن تجاوز حجم الحزمة 100 MiB. نجاح هذا الفحص لا يعني اكتمال المراحل أو الرسوم أو اختبار الهاتف.

## البناء والاختبارات
يتطلب Python 3.12 وNumPy وJDK 17 وAndroid SDK وGradle 8.9:
```bash
python -m pip install numpy
python tools/generate_audio.py
node tests/smoke-test.cjs
gradle assembleDebug --no-daemon
python tools/verify_apk_assets.py
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
