# مغامرات فريدة — مشروع لعبة Android

لعبة مغامرات وتعليم عربية للأطفال بطلتها فريدة. المستودع هو مصدر التطوير والبناء.

## ما يعمل في نسخة التطوير الحالية
- خمسة عوالم قابلة للاختيار وخمسة مستويات مفتوحة.
- أنشطة تعليمية للحيوانات والأشكال والألوان والحروف العربية.
- نظام بسيط للأرواح والعوائق والمقتنيات.
- ثلاث مقطوعات موسيقية أصلية، وثلاث خلفيات مرسومة، وشريط حركة لفريدة.
- واجهة عربية، تحكم لمس يمنع تمرير الصفحة، وتشغيل محلي دون إنترنت.

## فحوص البناء
اجتازت اختبارات المتصفح واللعب، وبناء Android وفحص سلامة APK. حجم APK التطويري المؤكد 119,542,496 بايت، ويتضمن الصوتيات والرسوم فعلياً.

## تنبيه حول الحالة
هذه نسخة تطويرية وليست بعد لعبة تجارية مكتملة أو إصدار Release موقّع. لا تزال الحملات التفصيلية والمهام والأعداء والزعماء والأنشطة التعليمية المتنوعة والتسجيلات الصوتية والاختبار على جهاز Android فعلي مطلوبة. لا يُستخدم حد الحجم وحده كدليل على اكتمال اللعبة.

## البناء
يتطلب Python 3.11 وNumPy وPillow وJDK 17 وAndroid SDK وGradle 8.7:

```bash
python -m pip install numpy pillow
python tools/generate_game_assets.py
cp index.html app/src/main/assets/index.html
node tests/smoke-test.cjs
gradle assembleDebug --no-daemon
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

راجع [GAME_DESIGN.md](GAME_DESIGN.md) و[PROJECT_STATUS.md](PROJECT_STATUS.md) لمتطلبات الجودة وآخر نقطة مؤكدة.
