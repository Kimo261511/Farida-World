# مغامرات فريدة – الإصدار 2.2

لعبة عربية تعليمية وترفيهية للأطفال، تعمل بالكامل دون اتصال بالإنترنت.

## المزايا
- صيد السمك باللمس وجمع النجوم.
- لعبة الألوان، الذاكرة، و20 لغزاً تعليمياً.
- الحروف العربية والأرقام.
- مرسم للرسم بالإصبع.
- شخصية فريدة مرسومة بأسلوب متجهي واضح داخل الواجهة وأيقونة تطبيق مخصصة.
- مؤثرات وموسيقى مولّدة محلياً باستخدام Web Audio، دون تنزيل ملفات صوتية.
- حفظ النجوم وإعدادات الصوت على الجهاز.
- شاشة أفقية مناسبة للهاتف والتابلت.
- لا إعلانات ولا مشتريات ولا صلاحية إنترنت.

## بناء APK
يُبنى التطبيق تلقائياً بواسطة GitHub Actions عند كل تحديث على فرع `main`.
افتح تبويب Actions لمتابعة البناء، أو قسم Releases لتنزيل ملف APK عند نجاح البناء.

## بناء محلي
يتطلب JDK 17 وAndroid SDK وGradle 8.7:
```bash
node tests/smoke-test.cjs
gradle assembleDebug --no-daemon
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات
- الموسيقى تبدأ بعد أول لمسة بسبب سياسات تشغيل الصوت في Android WebView.
- الإصدار الحالي APK تجريبي للتثبيت المباشر (debug)، وليس إصدار متجر موقّعاً للنشر.
